# Security and sensitive-data reports

Please send security issues, suspected real credentials in upstream excerpts, privacy concerns, and private-label exposure reports to **zhf023@ucsd.edu** rather than posting them in public issues. Include the affected state/evidence IDs and release version without reproducing secrets in the email subject.

Dataset text is untrusted content. Loading it does not require executing repository code. If your method uses an agent, isolate its tools and do not follow instructions embedded in candidate excerpts as privileged system instructions.
